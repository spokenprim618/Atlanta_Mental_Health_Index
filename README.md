# Metro Atlanta Mental Health Index (MHI)

A county-level composite index estimating relative mental-health need and
service-capacity gaps across 10 counties in the Metro Atlanta region:
Fulton, DeKalb, Gwinnett, Cobb, Clayton, Cherokee, Henry, Douglas, Fayette,
and Rockdale, Georgia.

Built as a HYS data science project. This repo contains the full,
reproducible pipeline: raw sourced data → composite index → visualizations.

|---|---|---|

Higher score = greater estimated mental-health vulnerability / unmet need.

## Indicators used in the index

We set out to gather 8 indicators (4 "need" + 4 "capacity") per county. Five
came back as clean, directly comparable county-level numbers and are used in
the index calculation:

| Indicator | Type | Data year | Source |
|---|---|---|---|
| Poverty rate (%) | Need | 2020–2024 (ACS 5-yr) | U.S. Census Bureau QuickFacts |
| Uninsured rate, under 65 (%) | Need | 2020–2024 (ACS 5-yr) | U.S. Census Bureau QuickFacts |
| Frequent mental distress (%) | Need | 2022–2023 | CDC PLACES, via County Health Rankings & Roadmaps 2025 |
| Unemployment rate (%) | Need | March 2026 | Georgia Dept. of Labor county profiles / BLS LAUS |
| Mental health providers per 100,000 | Capacity | 2025–2026 | County Health Rankings & Roadmaps 2025 |

Three additional indicators were part of the original research scope but are
**not** included in the numeric index — see "Data Limitations" below:

| Indicator | Status |
|---|---|
| Licensed mental health treatment facility count | Not available as a clean per-county number from SAMHSA/DBHDD without manual, address-by-address lookups |
| Mental Health Professional Shortage Area (HPSA) designation | Only a statewide figure confirmed (150 of 159 GA counties designated); county-specific status (full/partial/population-group) not confirmed |
| Inpatient psychiatric beds per 100,000 | Only available at the **state level** from KFF (21.78 combined inpatient+residential beds/100k, 2024) — no county breakdown exists in the public KFF dataset, so this can't distinguish between counties |

## Methodology

1. Min-max normalize each of the 4 "need" indicators to 0–1 across the 10
   counties (higher = worse).
2. Min-max normalize provider density (capacity), then invert it
   (`1 - normalized`) so higher = greater provider scarcity — same direction
   as the other components.
3. Average the 5 normalized components with **equal weights (20% each)**.
4. Rescale to a 0–100 score.

This is a deliberately simple, transparent first-pass approach — good for a
2-week project, but see below for how to make it more rigorous.

## Key findings

- **Clayton County** is the clear outlier — worst on every single input
  indicator (poverty, uninsured, mental distress, unemployment, and lowest
  provider density), which drives its MHI score well above the rest.
- **Fayette County** is consistently the healthiest on every metric.
- Poverty and unemployment are strongly correlated (r = 0.74) — somewhat
  redundant as separate index inputs, worth addressing in a future PCA-based
  weighting scheme.
- Provider density and frequent mental distress are negatively correlated
  (r = −0.66) — counties with fewer providers per capita report more
  distress. Suggestive, not causal.

## Data limitations (be upfront about these in any write-up)

- The "need" and "capacity" indicators come from different data years and
  reference periods (multi-year ACS averages vs. single-month unemployment
  vs. 2-year PLACES estimates) — they aren't perfectly time-aligned.
- Uninsured rate is calculated for the **under-65 population only** (the
  standard ACS convention), which slightly understates the *true* uninsured
  share by excluding seniors — though nearly all seniors have Medicare
  anyway, so this has limited practical effect.
- Psychiatric bed capacity is a **state-level figure applied uniformly to
  all 10 counties** — it cannot show real county-to-county capacity gaps in
  actual inpatient beds.
- Facility counts and precise HPSA designation status were not obtainable
  from static/scraped sources and require running each county through
  SAMHSA's treatment locator (findtreatment.samhsa.gov) and HRSA's Find
  Shortage Areas tool (data.hrsa.gov) individually.

## Suggested next steps / improvements

- **PCA-based weighting** instead of equal weights, to account for
  correlation between poverty and unemployment.
- **Sensitivity analysis**: recompute the index under 2–3 alternate weighting
  schemes (need-heavy vs. capacity-heavy) and check rank stability.
- **Z-score standardization** as a robustness check against min-max scaling,
  which is sensitive to Clayton's outlier values.
- Fill the 3 missing capacity indicators via manual SAMHSA/HRSA lookups, or
  substitute Georgia DBHDD's provider directory for facility counts.
- Add **youth mental health** (CDC YRBSS), **suicide rate / ED visit data**
  (Georgia DPH OASIS), and a **Social Vulnerability Index** layer for more
  outcome-oriented and demographic depth.
- Investigate **sub-county disparities** (e.g., by census tract) in the
  larger, more heterogeneous counties like Fulton and DeKalb, where a single
  county average likely masks large internal gaps.
